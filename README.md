# SalesPulse - Sales Analytics Dashboard

A responsive, single-page sales analytics dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- **Executive KPIs**: Total revenue, gross profit & margins, transaction volume, AOV, and quota target pacing.
- **Interactive HTML5 Canvas Visualizations**:
  - Revenue & profit trajectory (Daily / Monthly interval toggle with hover crosshair).
  - Sales by category (Interactive donut chart with dynamic legend).
  - Sales by channel (Bar chart breakdown).
  - Top performing products leaderboard.
- **Client-Side Data Persistence**: Powered by `localStorage` with rich demo data seeding and instant resets.
- **Full Sales Ledger**: Search, filter by category/channel/status, sort columns, pagination, add/edit sale modal, and CSV export.
- **Multi-Currency Support**: USD ($), EUR (€), GBP (£), CAD (C$), AUD (A$), and JPY (¥).
- **Zero Dependencies**: Pure HTML, CSS (no CSS variables), and vanilla JS.

## Getting Started
Simply open `index.html` in any modern web browser.
